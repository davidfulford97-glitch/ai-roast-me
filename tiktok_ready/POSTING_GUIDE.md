# TikTok Posting Guide

## How to post:

1. Open TikTok app
2. Tap + to create
3. Tap 'Upload' then select multiple photos
4. Select the 4 slides from each video folder (in order)
5. TikTok will create a slideshow
6. Add the caption and hashtags
7. Post!
